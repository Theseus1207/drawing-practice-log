# 繪畫練習紀錄

記錄繪畫練習的項目、件數、打卡、統計圖表與每週結算。資料保存在你使用的裝置瀏覽器中，不會上傳到任何伺服器。

## 使用方式

1. 用手機瀏覽器開啟網站（GitHub Pages 網址）。
2. 加到主畫面：
   - iPhone（Safari）：點分享按鈕 → 「加入主畫面」。
   - Android（Chrome）：點選單 → 「安裝應用程式」或「加到主畫面」。
3. 定期在「資料備份」區複製恢復碼保存。換裝置或資料遺失時，把恢復碼貼到「用恢復碼還原」即可。

## 注意

- 資料存在目前這台裝置的瀏覽器裡，清除網站資料或換手機前請先複製恢復碼。
- 恢復碼會覆蓋目前所有資料，還原前請確認。

## 本機執行

直接用瀏覽器開啟 `index.html` 即可；若要測試離線功能（Service Worker），請用 `python3 -m http.server` 之類的本機伺服器開啟。
